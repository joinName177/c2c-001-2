# c2c-001 · 人生时间投资所

Vue 3 + TypeScript + Vite 纯前端时间资产配置工具。用户可以设置每日/每周时间预算，将时间投入健康、学习、关系、事业、娱乐、休息六类资产，查看组合配置、ROI、人生资产负债表与再平衡建议。数据保存在浏览器 `localStorage`。

## 统计口径

- 自然周：周一 00:00 — 周日 24:00（本地时区），周编号为 ISO-8601 周；顶部账期与趋势图共用 `src/core/weeks.ts` 的同一套周界规则
- 总览、组合、分析、资产负债表均按**当周投入**与每周可配置小时对比；投资流水展示全部历史记录
- 趋势视图把每笔记录归入所属自然周（跨周不重复计入），逐周汇总分类小时与当周总投入，并对照每周预算标出超配/余量；无记录的周补零展示
- 对账：近 N 周合计 + 更早周合计 = 全部记录累计，与流水总额一致
- 分类连降信号只统计已完成周，进行中的本周不参与

## 分层

- 核心层 `src/core`：时间账户、投资记录、组合指标、ROI、资产负债表、建议规则与自然周趋势
- 端口层 `src/ports`：时间快照仓储接口
- 适配器层 `src/adapters`：浏览器本地存储实现
- 界面层 `src/ui`：Vue 页面与原生 CSS 视图
